## 3. 讨论结论

1. 采用课程官方参考选题“学生选题系统”，项目名称确定为 CourseMatch。
2. 第一版目标是让有限名额题目的选择过程规则公开、过程可复核、结果可解释，而不是只做题目展示和报名表。
3. 每个题目可以设置可容纳的学生人数；每名学生最终最多分配到一个题目。
4. 学生可按偏好填写 1 至 3 个不重复志愿。系统采用“志愿轮次优先”的唯一分配规则：先处理全体第一志愿，再处理未分配者的下一志愿；同一题目、同一轮次超额时按已冻结随机序号决定。
5. 所有已填志愿均未分配的学生进入补选池；补选竞争继续使用冻结随机序号，不强制分配不愿接受的题目。
6. 第一版不做学生组队管理、学生互换题目、AI 决策、多套可切换算法和未经记录的人工插队。
