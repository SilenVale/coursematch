# 全校教务课程目录（课种）— 计划与验收

> 状态：**MVP 实施中**（V1 主链不变；在 topic 上挂课种，助理匹配话术）

## 1. 要解决什么

- 教师说「软件工程」时，应对 **全校教务目录** 里的 **课种**，而不是另起一层与课无关的「活动名称」。
- **目录里已有**：在本轮选课下 **再开一个班**（topic），**挂同一课种**，不再新建课种。
- **目录里没有**：**确认课种 / 写入 topic 时** 登记新课种，之后其他教师可见、可挂靠。

## 2. 对外概念（课种 / 班 / 发布）

| 对外说法 | 含义 | 实现（库表，文档内保留） |
|----------|------|---------------------------|
| **课种** | 教务目录里的课，如「软件工程」；本轮对外名称与课种一致 | `course_catalog`；`activity.title` 与之对齐 |
| **班** | 某课种下你的教学班：教师、时间、名额 | `topic` + `catalog_course_id` |
| **发布** | 学生可填报志愿 | `activity.lifecycle` → `PUBLISHED` |
| **本轮选课** | 一次填报周期：起止时间、参与名单、发布/截止/分配 | `activity`（实现层不叫「选课活动」） |

学生志愿选 **班（topic 行）**；同课种多班 = 多行、同一 `catalog_course_id`、不同展示名（教师 · 课种）。
