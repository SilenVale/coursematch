# 全校教务课程目录（课种）— 计划与验收

> 状态：**MVP 实施中**（V1 主链不变；在 topic 上挂课种，助理匹配话术）

## 1. 要解决什么

- 教师说「软件工程」时，应对 **全校教务目录** 里的 **课种**，而不是仅当活动标题或重复文本。
- **目录里已有**：在本活动下 **新增一个教学班**（topic），**挂同一课种**，不再新建课种。
- **目录里没有**：**确认写入 topic 时** 登记新课种，之后其他教师可见、可挂靠。

## 2. 概念（三层）

| 层 | 含义 | 存储 |
|----|------|------|
| 活动 | 一场选课（名称、开始/截止、名单） | `activity` |
| 课种 | 教务目录一条，如「软件工程」 | `course_catalog` |
| 教学班 | 某活动下某课种 + 某教师/时间/名额 | `topic` + `catalog_course_id` |

学生志愿仍选 **topic 行**；同课种多班 = 多行、同一 `catalog_course_id`、不同 `title`（教师 · 课名）。
