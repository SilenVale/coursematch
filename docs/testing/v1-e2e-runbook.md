# V1 主链联调 Runbook

> 用途：干净环境按步骤走完 [V1_DELIVERY_PLAN.md](../V1_DELIVERY_PLAN.md) §1.1，供集成测试留证。  
> 预计 30～45 分钟（含环境准备）。

## 0. 环境准备

```bash
git clone https://github.com/SilenVale/coursematch.git
cd coursematch
cp .env.example .env
docker compose up -d
npm install
set -a && source .env && set +a   # macOS/Linux
npm run migrate && npm run seed
npm run test                      # allocation + API 单测
npm run dev:api                   # 终端 1 → http://localhost:3001
npm run dev:web                   # 终端 2 → http://localhost:5173
```

| 角色 | 账号 | 密码 |
|------|------|------|
| 教师 | `teacher01` | `Coursematch-Dev-2026` |
| 学生 A | `20260001` | 同上 |
| 学生 B | `20260002` | 同上 |

种子含：**已发布示例活动**（可填志愿）、**截止联调示例**（已截止，可冻结/分配演示）。

## 1. 教师 · 活动配置（石俊贤验收段）

1. 登录 `teacher01` → **活动配置**。
2. 可选：新建草稿 → 基本信息 → CSV 名单预览/替换 → 题目 → **发布**。
3. 或使用种子「已发布示例活动」确认可打开配置只读/编辑规则符合当前阶段。

**通过：** 未齐备不能发布；CSV 失败不破坏旧名单（若测新活动）。

## 2. 学生 · 志愿（刘家铭验收段）

1. 登出 → 登录 `20260001` → **志愿**。
2. 选择「已发布示例活动」→ 加入 1～3 个题目 → **保存志愿**。
3. 刷新页面，顺序与版本一致。

**通过：** 截止后同一活动为只读（可选：改系统时间或等截止，或只测联调活动）。

## 3. 教师 · 冻结与主分配（罗子超验收段）

1. 登出 → `teacher01` → **冻结/结果**。
2. 活动选 **「截止联调示例」**（或已截止且有名册的活动）。
3. **冻结** → 状态为已冻结。
4. **主分配** → 教师汇总出现各学生状态。
5. 打开 **证据** 区域（若有）确认快照与批次存在。

**通过：** `npm test` 中 ABCD 样例仍通过；同一活动再次分配为幂等（同一 batch）。

## 4. 学生 · 本人结果

1. 登录 `20260001` / `20260002` → **我的结果**。
2. 选择「截止联调示例」→ 应显示 **READY**（已分配 / 未命中 / 未提交之一）。
3. 未分配前同一活动应显示 **等待分配**（PENDING）。

**通过：** 与教师汇总中该生行一致（序号、状态、命中题）。

## 5. 教师 · 关闭

1. `teacher01` → 同一活动 → 填写关闭原因 → **关闭活动**。
2. 学生活动阶段变为 CLOSED，结果仍可只读查看。

## 6. 权限抽测（建议截图）

| 操作 | 账号 | 期望 |
|------|------|------|
| `POST .../allocation`（DevTools 或 curl） | 学生 | 403 |
| `GET .../preferences/me` 他人活动 | 学生 | 404 |
| `GET .../results/me` 他人活动 | 学生 | 404 |
| 教师写接口 | 学生 | 403 |

将步骤 1～6 的截图或终端输出填入 [V1_CHECKLIST.md](../V1_CHECKLIST.md) 对应行。
