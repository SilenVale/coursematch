| 项 | 内容 |
|----|------|
| 模块 | M3 志愿；M5 中 **仅学生本人结果** |
| 不做 | 活动配置/发布（石俊贤）；冻结、主分配、教师汇总/证据/关闭（罗子超） |

## 允许改动（默认仅此范围）

**后端**

- `apps/api/src/routes/activities/preferences.ts`
- `apps/api/src/routes/activities/results.ts` 中 **仅** `GET .../results/me` 相关逻辑（若文件与他人共用，用清晰函数边界，PR 说明）

**前端**

- `apps/web/src/pages/student/*`（志愿、题目浏览、本人结果等）
- 学生布局/路由最小接线

**禁止擅自修改**

- `config.ts`、`freeze-allocation.ts`、教师侧 `GET .../results` 与 `evidence`/`close`
- `packages/allocation/`、`packages/shared/`、迁移脚本

## 须实现的 API

| 方法 | 路径 | 角色 |
|------|------|------|
| GET | `/api/activities/:activityId/topics` | 学生视图（`canChoose`、热度等） |
| GET | `/api/activities/:activityId/preferences/me` | 学生 |
| PUT | `/api/activities/:activityId/preferences/me` | 学生 |
| GET | `/api/activities/:activityId/results/me` | 学生 |

题目列表 GET 可能与教师共用路由实现，但**响应形状**须按契约区分教师/学生（`StudentTopicView`）。

## 业务要点（第 1 版）

- 志愿 **1～3 个有序** topicId，**整单提交**；不占名额、不预分配。
- 截止后（`DEADLINE_REACHED` 及之后）：拒写志愿，前端只读（`DEADLINE_REACHED` 等错误码）。
- 本人结果三种态分开展示：**已分配**、**全落选**、**未提交**（见 `PersonalResultView`）。
- 结果与志愿 **只信 API**；禁止用前端推算最终去向。
