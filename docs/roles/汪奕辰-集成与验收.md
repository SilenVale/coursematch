## 合并 PR 前检查

1. 分支基于最新 `master`，diff 不越界（对照各任务卡「允许改动」）。
2. 是否改动 `shared` 或 `migrations` → 全员知悉。
3. PR 含个人验收勾选 + 可复现验证步骤。
4. `npm test` 与（若适用）本地主链 smoke。
