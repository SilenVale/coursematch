# 罗子超 · M4 冻结与主分配 + 教师侧 M5

| 项 | 内容 |
|----|------|
| 模块 | M4 冻结与一次主分配；M5 教师汇总、证据、关闭 |
| 不做 | 活动配置/发布（石俊贤）；学生志愿 UI 与学生 `results/me`（刘家铭） |

## 允许改动（默认仅此范围）

**后端**

- `apps/api/src/routes/activities/freeze-allocation.ts`
- `apps/api/src/routes/activities/results.ts` 中教师侧：`GET .../results`、`GET .../evidence`、`POST .../close`（与刘家铭协调同一文件时 PR 写清边界）
- `packages/allocation/`（纯函数 + 测试）

**前端**

- `apps/web/src/pages/teacher/FreezeAllocationPlaceholder.tsx` 及教师结果/证据/关闭 UI

**禁止擅自修改**

- `config.ts`、`preferences.ts` 学生路径
- 在 `apps/web` 或其它处复制一套分配逻辑

## 须实现的 API

| 方法 | 路径 |

| GET | `/api/activities/:activityId/freeze` |

| POST | `/api/activities/:activityId/allocation` |
| GET | `/api/activities/:activityId/results` |
| GET | `/api/activities/:activityId/evidence` |
| POST | `/api/activities/:activityId/close` |

## 业务要点（第 1 版）

- 截止后生成 **完整冻结快照** + 每人 **唯一 lotteryNumber**；`FREEZE_REQUIRED` / 半快照不可分配。
- 主分配算法 **仅** 调用 `packages/allocation`；规则见 [ALLOCATION.md](../ALLOCATION.md)（轮次优先 + 冻结序号，**禁止**按学生顺序逐个试三个志愿）。
- 同一快照再次 `POST .../allocation` 须 **幂等**（同一 `batchId`）。
- 成功主批次 **不可覆盖**；关闭须 `reason`；可保留空位与未分配学生。
- 教师侧 `GET .../preferences` 可为只读汇总（若由你实现，与刘家铭确认是否拆分）。
